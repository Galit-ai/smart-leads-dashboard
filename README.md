# דאשבורד ניהול לידים חכם

דאשבורד חכם לניהול לידים: קליטה, מעקב, תעדוף והמרה של לידים.
נבנה למכירת Joole לבתי מלון וללקוחות פרטיים.

## מה יש בו

- **לוח שלבים**: לפנות → פניתי → בשיחה → נסגר / לא רלוונטי. אפשר לגרור כרטיס בין עמודות או לבחור שלב מהרשימה.
- **למי לפנות היום**: רשימה אוטומטית של מי שעוד לא פנית אליו, מי שהגיע תאריך החזרה שלו, ומי שאין איתו קשר כמה ימים.
- **דירוג חם / פושר / קר**: ציון לכל ליד לפי סוג הלקוח (בית מלון שווה יותר), רמת העניין, השלב, כמות היחידות, ואם עבר הרבה זמן מהקשר האחרון.
- **טיוטת הודעה**: הודעה מוכנה לפי סוג הלקוח והשלב, עם העתקה בלחיצה ושליחה בוואטסאפ (אם יש מספר טלפון).

הלידים נשמרים בדפדפן (localStorage), כלומר רק במחשב ובדפדפן שבהם הוזנו.

## הרצה מקומית

```bash
npm install
npm run dev
```
