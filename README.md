# דאשבורד ניהול לידים חכם

דאשבורד חכם לניהול לידים: קליטה, מעקב, תעדוף והמרה של לידים.
נבנה למכירת Joole לבתי מלון וללקוחות פרטיים.

## מה יש בו

- **שתי רשימות נפרדות**: לקוחות פרטיים ובתי מלון, כל אחת בלשונית משלה עם מדדים ותזכורות משלה.
- **ייבוא מקובץ**: קובץ CSV מטופס לידים של פייסבוק/אינסטגרם, טיקטוק, לינקדאין או גוגל. מזהה עמודות באנגלית, גרמנית ועברית, מדלג על כפילויות ועל מי שמתחת לגיל 18.
- **קהל יעד** (לקוחות פרטיים): 18–21 מגרמניה, תחומי עניין לטירגוט והמלצות לכל פלטפורמה.
- **לוח שלבים**: לפנות → פניתי → בשיחה → נסגר / לא רלוונטי. גוררים כרטיס בין עמודות או בוחרים שלב מהרשימה.
- **למי לפנות היום**: מי שעוד לא פנית אליו, מי שהגיע תאריך החזרה שלו, ומי שאין איתו קשר כמה ימים.
- **דירוג חם / פושר / קר** לפי רמת העניין, השלב, המקור, מספר החדרים (למלונות) וזמן מהקשר האחרון.
- **טיוטת הודעה** בגרמנית, אנגלית או עברית, לפי סוג הלקוח והשלב, עם העתקה ושליחה בוואטסאפ.

JOOLE מיועד לבני 18 ומעלה: אי אפשר לשמור או לייבא ליד מתחת לגיל הזה.

הלידים נשמרים בדפדפן (localStorage), כלומר רק במחשב ובדפדפן שבהם הוזנו.

## הרצה מקומית

```bash
npm install
npm run dev
```
